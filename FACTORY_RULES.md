# Factory Rules

1. Read `MISSION.md` and `AGENTS.md` before writing.
2. Use a task-specific branch; never overwrite unrelated work.
3. Keep domain logic headless and validate the affected behavior.
4. Do not store secrets, private data, caches, generated artifacts or model weights.
5. A task passes only with the configured harness and a positive test count.
6. Merge, deployment, scheduling and paid calls require explicit project authorization.
