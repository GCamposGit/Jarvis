## Dark Factory project runtime

This repository owns its product rules. Dark Factory is an isolated, pinned runtime under `.factory/runtime/`; never import a sibling DarkFac checkout. Read `MISSION.md` and `FACTORY_RULES.md` before writing. Use `.agents/skills/` for workflows and run `python .factory/darkfac.py harness --quick` as the deterministic gate.

Autonomy level: **2**. Merge, deployment, scheduling, credentials and paid calls require the permissions declared by this project's governance.
